\begin{abstract}
This work studies model checking complexity and efficient translation of \GLs{}.
We show that model checkin for \GLs{} is EXPTIME complete,
and give an efficient translation to the order $2^{2^{\mathcal O (n)}}$.
This improves previous results which is to the order of $n$ iterated exponentials.
\end{abstract}
